## 尚未发布的工具准备改进

Mole 准备页改为提供实际分析适配器支持的 V1.57.0 官方文件，不再默认推荐不兼容的 Homebrew 安装。指引按应用架构显示固定下载地址、大小与 SHA-256；复制文本由用户自行审阅和运行，在新私有目录下载并核验后才添加执行权限，不执行分析器、不修改已有安装或移除隔离标记。新增官方直接分析器常见位置，以及中英文独立指引和命令渲染验证。

这些变化尚未进入 preview.6 安装包；实际已交付内容仍以对应版本记录为准。

## 后续工作

[0.1.0-preview.6](/changelog/0.1.0-preview.6) 已交付逐次确认的官方固定版本 Mole 目录分析、工具准备与文件／状态边界加固，提供 DMG 与 ZIP。Homebrew／自编译分析器、清理和真实 Git status 仍不属于该版本能力。后续应用改动只有在对应版本实际发布并核实后，才会标记为已交付。

中文测试自有视图、完整优化 Release 测试与定向内存检查已加入 CI。合成视图和自动检查的范围见对应版本记录，不代表完整窗口交互、VoiceOver 或真实 Mac 权限覆盖已验收。

文档网站源码、Fumadocs 中文指南、站内搜索、Docker 镜像与 Dokploy 配置指南已合入仓库，但公开站点部署和生产域名尚未完成。网站独立部署，不是 App 安装包的一部分。

原生视觉、VoiceOver、双架构实机体验与真实进程权限覆盖仍需手动验收。后续版本以独立 Markdown 记录保存实际交付内容和验证范围。
