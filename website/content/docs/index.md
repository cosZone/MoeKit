## 从这里开始

MoeKit 是面向 macOS 的个人 CLI 工具箱。Mole 是第一个内置模块，工具箱的边界不止于磁盘整理。

当前已交付 [preview.8](/changelog/0.1.0-preview.8)：新增逐次确认的精确进程停止，以及原生多缓存废纸篓、原路径恢复和另行确认的记录内缓存永久删除；同时保留项目发现、报告阅读、官方固定版本 Mole 目录分析与单个 Downloads 磁盘映像操作。**页面中出现某个工具入口，不代表它已经能执行命令。**

- [安装与预览](/docs/installation)：系统要求、构建方式和签名限制
- [功能状态](/docs/status)：哪些已实现，哪些仍在计划中
- [项目管理](/docs/projects)：从你选择的目录发现 Git 项目
- [Mole 空间分析与报告](/docs/mole)：目录分析、报告阅读及独立确认的原生缓存／磁盘映像操作
- [进程与端口](/docs/processes)：主动读取本地快照，查看关联证据及复查确认精确停止
- [更新日志](/changelog)：每个版本保留一份普通 Markdown

## 三个工作区

| 工作区 | 负责什么 | 当前边界 |
| --- | --- | --- |
| Projects | 项目列表、搜索、排序、置顶、详情、Finder 定位 | 只读发现，不检查 Git 工作区是否干净 |
| Tools | Mole 分析与报告、原生缓存操作、单个 Downloads `.dmg` 废纸篓／恢复，以及 Processes & Ports | 文件操作需独立确认与严格检查；停止需独立确认精确身份；不执行任意命令或广域清理 |
| Tasks | 当前会话的任务状态、取消、结果与 Diagnostics | 退出应用后不保留任务历史 |

## 第一次打开

正常启动没有示例项目、虚构测量或演示运行结果。可以选择目录发现项目、导入已有报告，或在 Mole Space 选择受支持的官方分析器与目录，复查并确认后开始分析。进程列表需要你明确点击刷新。

实际分析只接受精确匹配的 Mole V1.57.0 官方原始二进制；Homebrew、自编译与其他版本不受支持。工具以普通用户权限运行，不是 OS 沙箱；确认会说明读取范围和私有副本、缓存与临时目录的写入。详见 [Mole 分析边界](/docs/mole)。

想先看看布局，可以在 **Settings → Preview** 开启 Demo。演示模式持续显示示例标识，退出后恢复真实数据；演示数据不写进真实项目目录。

## 项目与许可

源码位于 [cosZone/MoeKit](https://github.com/cosZone/MoeKit)。项目许可证尚未确定，公开源码不代表授予额外许可。Mole 是独立的上游项目，本仓库不附带它的可执行文件，也不复制其 GPL 实现。
