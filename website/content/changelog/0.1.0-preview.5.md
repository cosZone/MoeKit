## 先了解，再开始

- 新增原生上手引导，提供“整理我的项目”“查看进程与端口”和“先看看示例”三个入口，先说明当前可用功能、读取范围与下一步
- 只有首次使用、真实项目列表健康且为空时才自动展示；已有项目、列表读取出错或显式 Demo 启动时不会自动弹出
- 可以返回、跳过或关闭，也能从 Help → Getting started、Settings → General → Getting started 重新打开；关闭记录仅额外保存一个本地引导版本整数，不记录所选目标、路径或时间
- 引导完成后进入对应工作区。进入 Projects 或 Processes & Ports 不会自动扫描、打开文件夹选择器或请求权限，仍需主动选择文件夹或点击 Start scan / Refresh

## 空状态给出下一步

- 空项目、任务、未扫描进程与未导入的 Mole Space 页面说明各自实际可用的操作，不再让新用户只面对空表格
- Mole 尚未接入的能力提供返回已实现 Space 报告导入的入口；不会执行清理、卸载或维护
- 修正空 Tasks 表格内容区域的宽度收缩，并覆盖引导、空工作区和现有 Demo 任务的渲染检查

## 数据与验证范围

“先看看示例”使用现有 Demo 样例与持续可见标识；进入 Demo 不扫描目录或进程、不导入报告，也不把示例写入真实项目列表。应用初始化仍会加载已有本地项目列表，引导不会替换或修复该文件。

补充了首次展示、跳过／关闭、被打断后再次启动、返回与重开、真实／Demo 切换、无扫描副作用和列表原数据保留的状态测试。中英文、浅深色及两种尺寸的测试自有视图已检查；较小尺寸的引导内容可以滚动。

合成渲染没有操作实际桌面窗口。窗口前后顺序、关闭最后一个主窗口后的重新打开、焦点、键盘遍历、VoiceOver 和真实 Mac 权限仍需手动验收，不把模型测试和图片检查当作这些交互已经通过。

真实 Git 状态仍为“Not checked”；Mole CLI 执行、目录清理、进程停止与强制停止均未启用。继续提供通用 DMG 与 ZIP，使用 Apple Development 开发签名，尚未公证。
