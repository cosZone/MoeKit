## Mole 安装与升级

- **版本提示更清楚**：显示已安装版本与已测试的 1.58.0，区分格式过旧、文件未验证与版本尚未测试。现有 Homebrew 安装优先，不再笼统提示“不兼容”
- **复用现有安装**：支持经过核验的官方 1.57.0／1.58.0 分析器；其他符合要求的 Homebrew 官方构建可主动联网验证，每次分析另行确认，结果仅供查看
- **终端内确认升级**：先展示实际的 Homebrew 更新与 Mole 升级命令，在终端中按回车才开始；支持交互输入、Ctrl-C 与停止，结束后重新检测安装

Homebrew 会安装当前提供的版本，不保证恰好为 1.58.0。更新可能影响 Homebrew、Mole 与依赖；取消不会回滚已发生的更改。

macOS 15+，Apple Silicon / Intel。Apple Development 签名、未公证；preview.9 及更早需先手动安装一次。
