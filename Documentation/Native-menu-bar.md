# 原生菜单栏交互

本页描述当前源码新增的菜单栏体验；实际交付版本和精确提交的构建结果以发布记录为准。

- 点击 MoeKit 自家幽灵工具箱图标打开紧凑面板；仅点击时轻轻点头，约 0.7 秒后静止。重复点击不叠加动画，任务忙碌使用静态时钟标记
- 面板保留打开工作区、设置、检查更新和退出；右键或 Control 点击打开原生菜单。Command 拖动交给系统，键盘打开、Escape、焦点离开沿用原生弹出层行为
- 图标使用原创 AppKit 矢量模板绘制，随系统菜单栏着色；页内状态同时有文字和形状，避免只靠颜色。开启系统“减少动态效果”时关闭点击和弹出动画
- 根据当前工作区已存在的模型显示忙碌和待查看问题。完成、取消仅来自真实会话任务记录；保留、未知、部分失败和持久修改错误不会被旧的成功记录覆盖。Demo 独立标明示例，不播放模拟后台任务
- 菜单栏读取现有内存状态，不扫描、执行工具、连接 Docker、读取恢复记录、创建日志或授权文件修改。打开面板不改变当前确认。缓存清理 store 改为工作区持有，但原有关闭视图取消、实时上下文复查和逐项确认保持生效
- 面板关闭、隐藏菜单栏、睡眠、显示器变动、状态/模式变化与应用退出会停止动画；没有常驻动画定时器或轮询。主工作区重开使用当前 Space，窗口关闭由 AppKit/SwiftUI 管理

## 实现

- `Sources/MenuBar/MenuBarIcon.swift`：原创小尺寸吉祥物模板与单次关键姿态
- `MenuBarActivity.swift`：真实任务和原生操作结果归纳；无后台任务推断
- `MenuBarController.swift`：NSStatusItem、NSPopover、SwiftUI hosting、观察和生命周期
- `MenuBarPanelView.swift`：独立英文/简体中文面板；不新增修改用户数据的入口

未复制 Magpie 的源代码或品牌素材，也没有 WebView、非公开 KVC、全局屏幕捕获或辅助功能权限请求。

## 自动验证与人工边界

新增单元测试覆盖状态优先级、部分结果、取消、Demo 隔离、缓存 fake executor、观察更新器状态、动画重入/停止与当前 Space 属性。原生渲染测试提供英/简中、浅/深色的六类面板状态和完整 1×/2×图标姿态表；脚本验证完整覆盖、尺寸、语言及数据范围。这些是待审的自有离屏视图，不是用户菜单栏截图。

仍须在实际 macOS 会话验收：鼠标/键盘和 VoiceOver 操作、打开期间高亮、Command 拖动、多显示器/刘海、全屏 Space、系统减少动态效果实时切换、睡眠恢复。源码检查和离屏渲染不能证明这些已实机通过。
