# MoeKit brand assets

Approved ghost-and-toolbox artwork, version 1. The SVG is the design source; PNG and AppIcon renditions are packaging assets. Only size conversion is applied to the approved PNG.

Palette: pink `#F4B5CD`, lavender `#C0B9E2`, blue `#87C7EA`. The app icon is custom artwork. App navigation/action icons use Apple SF Symbols, not custom web icons or emoji.
