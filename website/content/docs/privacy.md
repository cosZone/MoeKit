## 本地数据

项目目录保存于应用自己的 Application Support 目录。项目名、路径、置顶状态与最近 Finder 定位时间用于本地工作台。

上手引导仅额外保存本地关闭版本号，用于决定是否再次自动展示；不记录所选引导目标、路径或时间，也不自动扫描。应用初始化仍会读取已有的本地项目列表。

导入报告、任务记录和进程快照是会话内数据，不上传进程历史。应用当前没有遥测或云同步实现。后续新增网络或执行能力需要重新审视这些边界。

用户确认原生文件操作后，Downloads 磁盘映像与缓存工作流分别在应用的私有本地目录保存操作记录；缓存记录包含精确路径、内容清单和逐项结果，用于另行确认恢复或永久删除。打开页面不会自动读取恢复记录、重试或回放操作。记录可能包含私人路径，分享诊断前需要复查和脱敏。

## 文件读取

发现只从用户选定目录开始，不跟随符号链接，不执行项目脚本。Mole JSON 导入只读取选定文件，不沿报告路径继续访问文件系统。

实际 Mole 分析是独立的逐次确认操作：仅执行精确受支持的官方 V1.57.0 分析器，使用普通用户权限。确认会披露选定范围及私有分析器副本、缓存和临时目录的创建与回收；原有 Mole 缓存不被使用。固定分析路径不修改或删除所选内容，但附带元数据读取可能超出目录，不能把它视为操作系统强制隔离。

这些范围检查不是 App Sandbox。当前没有 App Sandbox entitlement，不能把应用行为限制当成系统隔离保证。

## 进程读取

只显示当前有效用户可读的进程。参数、环境变量、浏览器配置和 Cookie 不在读取范围内。权限失败与读取竞态会保留为不完整状态，不显示为虚构的空数据。

preview.8 的精确进程停止必须单独复查并确认；浏览器、应用、共享服务等受保护目标不能借此停止。信号结果仅保留于本次会话，强制停止须另一次新确认；不能从目录关联或端口推断 AI 专用浏览器归属。具体后果和取消边界见 [进程与端口](/docs/processes)。

## Git 整理与恢复数据

Git 整理只处理明确选择和逐次确认的受支持目标，不运行 live 仓库的 hooks、filters 或外部配置。已安装 Apple 签名 Git 的临时副本只检查 app 自有对象副本；不 fetch、不发送仓库数据、不自动下载安装 Git，也不提供 OS 沙箱保证。

确认后，工作树／登记或分支 ref 移入主仓库 `.git/moekit-recovery/` 的操作目录，保存原路径、提交和阶段记录。数据继续占用存储，会话内恢复需另行确认；重启后不自动扫描、恢复或删除。记录与恢复内容可能含私人数据，不是独立 Git bundle 或异地备份；分享前复查并脱敏。完整限制见 [项目管理](/docs/projects)。

## 更新请求与应用替换

[preview.10](/changelog/0.1.0-preview.10) 已交付 Sparkle 更新器。后台检查通过标准提示或 Settings 选择，自动下载安装默认关闭；更新请求访问固定 GitHub feed 与本仓库版本资产，可能携带应用版本，服务端可见 IP 地址。不发送项目／任务内容或系统画像，更新说明禁用 JavaScript。版本源和更新 ZIP 均要求签名，ZIP 在解压前验证，签名失败没有未签名回退。

应用替换保留包外的项目清单、置顶、偏好与私有恢复记录；不会主动清理用户项目或因失败重置数据。原生修改／分析操作忙碌时会阻止为更新退出；会话内扫描、报告和任务记录不承诺跨重启保留。真实生产安装的更新和权限迁移仍需验收，开发签名与未公证限制见 [安装说明](/docs/installation)。

[preview.9](/changelog/0.1.0-preview.9) 及更早版本没有自动安装器，升级到本版需先手动安装。旧版手动检查和更新器未启动时的备用入口只请求本仓库公开 Releases API，不使用认证、Cookie 或持久网络缓存；用户自行在浏览器下载安装。两种更新路径不应混淆。

## 文档网站

本站用于阅读文档，不连接或控制你的 Mac。站内搜索由同一网站服务处理，不需要第三方搜索账户；搜索词会发送给你正在访问的文档服务器，部署者的代理或访问日志可能记录请求 URL。

网站没有接入分析 SDK、外部字体、登录或广告服务。主题偏好由界面框架保存在浏览器本地。点击 GitHub 等外部链接后，适用对应服务的规则。

## 报告问题

提交 Issue 前检查日志和截图中的本地用户名、项目路径、端口及其他私人信息。不要提交证书、P12、密码、令牌、密钥或隐藏配置。

安全问题涉及可利用细节时，先使用仓库提供的安全联系渠道；如果尚未设置私密报告入口，不要把凭据或可利用细节直接公开。
