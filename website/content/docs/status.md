## 当前已实现

| 能力 | 行为 | 不包含 |
| --- | --- | --- |
| 项目工作台 | 原生 Table、搜索与排序、inspector、置顶、Finder 定位 | Git 状态检查、项目脚本运行 |
| 项目发现 | 用户选目录后，有限度地读取 Git 布局并勾选导入 | 全盘自动扫描、跟随符号链接 |
| 项目持久化 | 保存名称、路径、置顶、最近 Finder 定位时间 | 云同步、项目文件修改 |
| Mole Space | 导入用户选择的 analyze JSON，呈现覆盖与大小 | 运行 Mole、计算可靠可回收空间 |
| Processes & Ports | 主动读取当前有效用户的进程与 TCP 监听端口 | 自动轮询、命令参数、环境变量、CPU/内存监控 |
| 进程检查计划 | 精确保留所选身份，提示变动和风险 | 停止、强制停止、向进程组发信号 |
| Tasks | 本次会话的任务、取消、结果与诊断 | 跨重启的任务历史 |
| Demo | 显式开启，持续标识，与真实状态隔离 | 启动即伪造真实结果 |

## 尚未实现

- CLI 启动和执行管线
- Mole 清理、卸载与维护操作
- 进程停止和强制停止
- 实时系统指标、后台自动扫描
- 提权、特权辅助进程
- 任意第三方脚本或二进制插件加载
- 持久任务历史与自动更新

界面中的 Clean、Apps、Maintenance、Status 工作区和停止计划属于入口或预览，不代表以上执行能力已经开放。

## 怎样看验证记录

检查某项结果时，必须同时核对源码 SHA 和该提交的 [Actions](https://github.com/cosZone/MoeKit/actions) 记录。

- 结构检查通过，不代表 Swift 可以编译
- Swift 测试通过，不代表界面、VoiceOver 或真实权限场景已验收
- 一个架构上的测试通过，不代表两种芯片都经过实机测试
- 应用短时间保持运行，只是存活检查，不是完整操作验收
- 签名成功，不代表已经公证或发布

原生视觉、辅助功能、双架构实机体验和真实进程读取覆盖仍需手动检查。完整清单见 [仓库验收文档](https://github.com/cosZone/MoeKit/blob/main/Documentation/Verification.md)。
