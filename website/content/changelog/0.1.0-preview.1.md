## 本版本包含

- Projects：原生表格、搜索、排序、详情 inspector、置顶与 Finder 定位
- 选择目录后的有界只读 Git 项目发现，勾选导入与本地项目目录持久化
- Projects / Tools / Tasks 三个原生工作区与自定义应用图标
- Mole Space：导入 analyze JSON，保留 known / partial / unavailable / unknown 覆盖语义
- Processes & Ports：用户主动读取当前有效用户的进程与 TCP 监听端口，查看工作目录关联证据
- 精确保留所选进程身份的检查计划预览，不包含信号执行器
- 当前会话中的任务、取消、结果详情与 Diagnostics
- 显式 Demo 开关、持续示例标识、真实与示例状态隔离

## 明确尚未实现

CLI 执行、Mole 清理与卸载、维护、进程停止与强制停止、实时系统指标、提权、动态第三方插件、持久任务历史及自动更新。

报告数值不等于可回收空间；项目关联不等于进程所有权；检查计划不代表可以结束进程。

## 预览分发边界

本签名预览使用 Apple Development 证书，不是 Developer ID 分发签名，也没有 Apple 公证。Gatekeeper 仍可能阻止打开，不承诺任意 Mac 都能直接运行。

公开的三份产物已经下载并核对校验和。此版本不包含后来加入的 About 窗口与文档网站；它们记在 [尚未发布](/changelog/unreleased) 中。没有自动更新器。

## 验证范围

该发布运行通过 132 项 Release Swift 测试与 45 项发布辅助测试；测试只运行 CI runner 的当前架构。独立的 Debug CI 通过 10 秒显式 Demo 存活检查。自动化结果按上述精确源码 SHA 查验。

原生视觉、VoiceOver、双架构实机运行及真实进程权限覆盖仍需手动验收。源码中的测试、CI 构建、应用存活检查、签名和发布是不同阶段。
