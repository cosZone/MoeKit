# 发现、身份与扫描

状态：planned。本文是产品与实施蓝图，尚无可运行应用或已验证的执行能力。

## 发现与扫描

1. 首次使用只要求选择项目目录，支持拖放和手动添加仓库。可能的常用目录只作为可选建议
2. 初次扫描设置深度、条目数和时间预算，用户可主动扩大范围；发现结果必须标明是否完整
3. 默认不跟随目录符号链接、不跨卷、不深入应用包和大型依赖目录。发现阶段的剪枝不能用作删除前的完整检查
4. 找到仓库后，由 Git 枚举关联 worktree。根目录外的 checkout/common directory 先显示位置，获得访问后再检查
5. 保留规范路径与可用的文件/卷身份，处理路径替换、大小写敏感卷和独立 clone；不要简单转小写去重
6. 缓存结构库存，按需刷新选中行和失效仓库。FSEvents 仅作为“需要复查”的信号，不能证明目录未发生变化

“最近提交”“目录修改时间”“未发现活动进程”都不是闲置证明。活动检测只能作为保护线索，明确显示来源、时间和覆盖局限。
