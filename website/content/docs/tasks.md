## 任务列表

Tasks 汇集当前会话中的发现等任务，提供状态、取消入口与底部结果详情。需要排查不完整结果时，展开 Diagnostics 查看原因。

取消是协作式的：正在执行的单次系统调用不一定能立刻中断。取消后返回的过时结果不应覆盖更新的请求或跨过真实 / Demo 状态边界。

## 记录的生命周期

项目目录单独保存在本地；任务历史和已导入报告只保留于本次应用进程。重启后没有持久任务历史。

进程任务只记录状态与数量，不保存完整进程快照。不要把会话记录当作审计日志。

## 使用 Demo

在 **Settings → Preview** 显式启用 Demo。页面持续显示示例标识，真实项目目录不会被写入演示项目。

- 开启时切换到专门的示例数据
- 不进行真实进程扫描
- 切换模式时清空进程快照、选择和计划
- 退出时恢复真实工作区

也可以使用 `open -n …/MoeKit.app --args --demo` 单独启动演示。这里的省略路径必须换成你实际构建的应用路径。
