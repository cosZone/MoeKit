## 读取更可靠

- 项目 Git 元数据、Mole JSON 报告与 MoeKit 自身的项目列表文件（projects.json）采用有大小上限的普通文件读取；打开后再次检查文件类型与大小，拒绝末级符号链接和特殊文件
- 修复检查后文件被替换为 FIFO 时可能等待写入者的问题；读取过程中检查取消、超限与可观察到的改写，失败时保留未知或错误状态
- 报告在读取中变化会提示重新选择重试；导入仍只读取选定 JSON，不根据报告中的路径访问或改写文件

## 项目列表保存与恢复

- 损坏、截断、带有不支持的新字段或冲突记录的项目列表文件保留原始数据，不再用空列表回退结果覆盖原文件
- 重复项目 ID、重复规范化路径和无效父子关联会被拒绝，不自动删除、合并或修复记录
- 保存前比较已加载内容与当前文件；发现其他窗口或外部程序改动后，保留外部数据并提示当前更改尚未保存，需要重新打开以加载最新项目列表
- 权限或写入失败会明确提示临时更改；保留原有项目列表数据，恢复可写条件后可重试。刷新与 Demo 切换继续保留项目身份、自定义名称、置顶和最近定位记录

## 验证与范围

新增覆盖 FIFO、符号链接、超限文件、改写与取消的读取回归测试，以及异常列表、外部更改、保存失败和真实／Demo 状态隔离测试。磁盘写满通过注入错误测试；只读目录和拒绝访问场景使用临时文件夹验证，不操作用户的实际项目数据。

项目列表文件仍使用现有未版本化格式，没有自动迁移或修复。保存前比较是尽力冲突检查，不是文件系统级比较并交换；比较完成到原子替换之间仍可能与另一个写入者竞争。祖先目录替换等文件系统竞态及远程文件系统硬超时也未被完全解决。

保存仅涉及 MoeKit 自身的项目列表，不写入所选项目内容。项目发现、报告导入与进程快照保持只读；真实 Git 状态仍显示“Not checked”。Mole 执行、目录清理、进程停止与强制停止均未启用，Settings 仍只在当前会话生效。

继续提供包含同一份通用 App 的 DMG 与 ZIP，使用 Apple Development 开发签名，尚未公证。测试自有视图已增加中文渲染覆盖；合成图片仍不代替完整窗口、键盘、VoiceOver、双架构实机和真实权限验收。
