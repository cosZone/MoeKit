## 主动读取，只读观察

进入 Tools → Processes & Ports 并主动刷新。模块通过 macOS 原生 API 获取当前有效用户的可读进程，不运行 shell，不启动常驻守护进程，不定时轮询，也不请求 root。

读取可取消；进程快速退出、权限限制或读取预算用尽会显示为部分覆盖。快照不是整台系统在同一瞬间的原子记录。

## 可以看到什么

- PID、内核启动时间、UID、进程名和可执行文件路径
- 父 PID 与进程组
- 可读时的当前工作目录
- 可读时的 TCP 监听端点
- 捕获时间、不完整原因与未知字段

不读取命令参数、环境变量、远程连接端点、Cookie、浏览器配置或项目内容。没有 CPU 与内存采样，也不是完整的 Activity Monitor 替代品。

“未观察到 TCP 监听端口”只代表本次逐进程描述符检查没有看到监听端口，不代表进程没有网络连接。

## 项目关联是什么证据

规范化后的工作目录包含于已加入项目的路径中，才构成观察到的关联。匹配会检查目录组件边界；更深且唯一的项目根优先。重复根、无法读取或含糊的路径保持未关联。

父 PID、名称、端口、运行时间、PPID 1 或缺少父进程都不能证明所有权。此阶段没有启动台账，不会把进程标成“由 MoeKit 启动”。

## 停止计划不会停止进程

计划只保留你精确选择的进程身份，不会扩展到父进程、子进程或整个进程组。搜索、项目筛选、刷新、选择或 Demo 状态变化会使已打开的预览失效。

**当前没有发送信号的执行器。** 身份检查模型会识别陈旧快照、PID 重用和可观察到的元数据变动，但不能保证消除检查到执行之间的竞态，也不能可靠识别相同路径的重新执行。

浏览器、IDE、shell、数据库、虚拟机和共享服务等提示用于保守审阅，不是可随意结束进程的许可。未来执行器需要独立安全审查。

## 数据保留

快照、选择和计划仅在内存中存在，切换 Demo 时清空。Demo 不扫描或显示真实进程。任务条目只保留扫描状态及数量，不保留进程名或路径；进程历史不会持久化或上传。
