## 项目发现与复查

- 可一次选择最多 32 个根目录，共享扫描预算，查看进度并取消；某个目录失败时保留其余结果，同时明确显示部分读取状态
- 发现结果支持按名称、路径和分支搜索、排序、批量勾选后导入；重新导入同一路径会刷新元数据，并保留项目 ID、置顶、自定义名称和最近定位时间
- 校验 Git 共享目录与反向关联证据后，展示已导入主仓库和 linked worktree 的分组；不把普通 gitfile 一律当作 worktree
- 分支与 worktree 锁定信息带观察时间；清理安全复查解释保护原因，不提供删除操作或可回收空间估计

## 进程与端口

- 新增全部进程、TCP 监听与端口未知的分类视图，数量随当前搜索范围变化；可按本地监听地址、端口和传输类型搜索
- 更明确地显示项目关联的目录证据、未关联原因和无法读取的项目根目录；修正 `/tmp` 与 `/private/tmp` 这类规范化路径差异造成的漏关联
- 刷新、取消或失败后，保留的旧快照会显示其状态；首次扫描的空状态与尚未扫描不再混淆
- 筛选改变会使隐藏的选择与旧检查预览失效；停止计划分别统计需保护的目标，仍不能执行停止或强制停止

## 工作区操作与界面

- 搜索命令跟随当前工作区：Command-F 聚焦对应搜索框，Escape 先清空搜索再离开焦点；项目详情可用 Command-Option-I 开关
- 项目折叠、筛选和任务状态变化后，隐藏的旧选择会清除；清空筛选不会重新激活旧操作目标
- 窄窗口下收拢项目操作，任务摘要可滚动阅读；空列表、无匹配结果、报告导入中和未选择记录有更明确的提示
- Demo 与真实模式切换时清理搜索、筛选和选择；示例记录继续明确标识，避免真实数据与示例状态混用
- 补充搜索、列表和选中状态的辅助功能名称及中英文文案；这些改进尚未完成手动键盘与 VoiceOver 验收

## 验证范围

新增由测试自身持有的 SwiftUI/AppKit 视图渲染检查，覆盖 Projects 详情、Tasks 结果、Mole Space 与 Processes Demo 状态，在两种尺寸和深浅色下生成 16 张合成示例图片。已检查对应图片；它们不捕获桌面、真实目录或真实进程，也不代表标题栏、工具栏、中文布局、键盘交互或 VoiceOver 已通过验收。

## 安全边界

这些改进仍由用户主动触发，并且只读观察。项目发现不运行 Git、shell、项目脚本或 hooks。未提交／未跟踪文件、未推送提交、远程可达性和正在使用状态尚未核验，未知状态不会被视为可以清理。Git 状态解析器与模型只增加了内部测试准备，实时状态读取仍未启用，真实项目继续显示“Not checked”。

进程关联只代表观察到的工作目录关系，不代表由 MoeKit 启动或拥有该进程。Mole 清理、目录删除、进程停止与强制停止仍未启用。

继续沿用 DMG 与 ZIP 交付方式以及 Apple Development 开发签名；尚未公证。完整原生视觉与交互、VoiceOver、双架构实机体验和真实权限覆盖仍需手动验证。
