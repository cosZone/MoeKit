## 找到兼容的 Mole 分析器

Mole 的工具准备窗口改为提供实际分析适配器支持的 [V1.57.0 官方发布](https://github.com/tw93/Mole/releases/tag/V1.57.0) 文件，按当前应用架构显示 `analyze-darwin-arm64` 或 `analyze-darwin-amd64` 的固定下载地址、文件大小和 SHA-256，不再默认推荐不兼容的 Homebrew 安装。

- 可以查看并复制下载命令，再自行审阅和运行。命令在主目录创建新的私有文件夹，下载固定文件，核对大小和 SHA-256 后才添加执行权限，并显示可供选择的 `analyze-go` 路径
- 复制本身只更新剪贴板，不打开终端、不下载、不安装或运行分析器；命令不会覆盖已有安装、修改 PATH、执行上游安装脚本或自动删除下载目录
- 增加官方脚本安装的常见位置 `~/.config/mole/bin/analyze-go`。找到文件仍只表示“已找到 · 未验证”；每次分析都重新校验实际文件并确认范围，不能选择 `mo` 包装脚本
- Homebrew、自编译和其他版本仍不受支持。浏览器下载可能带有隔离标记；应用与复制命令都不移除隔离标记或绕过 Gatekeeper，遇到安全警告时不要通过换下载途径规避

## 将一个下载磁盘映像移到废纸篓

在 Tools → Mole → Space 对当前用户的真实 Downloads 目录完成一次受支持的 Mole 分析后，可从当前结果中选择一个直接位于该目录下的常规 `.dmg`，独立复查路径、大小、检查范围与影响，明确确认安装及使用已经结束，再移到 macOS 原生废纸篓。分析结果只提供选择线索；新的检查与这一次确认才允许操作。

- 只支持本地内置 APFS，且每次重新核对文件及祖先目录身份、权限与 ACL、项目列表保护和可观察的使用状态。不支持 `.pkg`、嵌套文件、批量操作、项目或 worktree、链接、云占位、网络或可移动卷；未知或改变的证据会拒绝操作
- 必须取得完整且为空的已挂载磁盘映像清单。只可自行推出自己打开的映像；系统管理的映像应保持原状，它们存在时该操作可能持续不可用。MoeKit 不自动推出任何映像
- 使用检查只覆盖可完整读取的当前用户文件描述符与 fileport，不证明全局未使用；内存映射、其他用户、系统服务及检查后新出现的使用不在证明范围内
- 导入 JSON、Demo 和单独选择路径不能授权移动文件。选择、分析、模式或项目列表改变会使旧计划失效；确认仅可使用一次，计划过期后需要重新复查
- 启动和打开页面不会自动扫描；主动准备计划只执行只读复查，不创建恢复记录或移动文件。移到废纸篓不会立即释放磁盘空间，也不代表文件内容已经被判定为可以丢弃

## 恢复需要另一次确认

确认操作后，MoeKit 在自己的私有应用数据目录保留操作记录，并核对 macOS 返回的实际废纸篓位置与文件身份。恢复入口只读取这些记录，不扫描任意废纸篓内容，也不自动重试或恢复。

恢复必须重新检查当前文件及原始目录，并对这份记录另行确认；只尝试回到原来的 Downloads 路径，目标已经存在时绝不覆盖。废纸篓被清空、文件身份或卷改变后可能无法恢复；不确定结果会保留可保留的数据并停止，不把文件消失当作成功。Finder 的“放回原处”可能指向内部暂存位置，应使用 MoeKit 的凭据恢复入口复查原路径。

此边界面向普通、合作的本地使用，不保证抵御恶意同用户进程竞争，也不保证检查之后无人打开文件。这项原生文件操作不清空废纸篓、不永久删除文件、不提权、不发送进程信号或修改系统安全设置。

## 验证范围与预览交付

新增单次确认、取消与过期、真实／Demo／导入边界、文件替换、ACL 与挂载拒绝、记录失败、恢复冲突和不确定结果的回归检查；原生 Trash／恢复测试只操作唯一且由测试持有的合成目录与文件。中英文确认和恢复视图增加渲染与可见性检查。

原生使用检查需要按对应提交的 CI 记录区分“当前完整检查未观察到使用”和“不支持当前运行环境”；历史正例或句柄诊断不能授权当前文件操作。具体构建、测试、签名及下载校验以最终发布记录为准。合成渲染和自动化检查不等于完整原生窗口、键盘、VoiceOver、双架构实机或真实用户目录权限已通过手动验收。

广域 Mole 清理、卸载、维护、项目删除、任意进程停止和真实 Git status 仍未启用；实验性 Git 工作不包含在本版。现有目录分析保持逐次确认，不因新增废纸篓入口变成自动清理。

继续沿用包含同一份通用 Release App 的 DMG 与 ZIP，支持 macOS 15+、Apple Silicon 和 Intel，并附 `SHA256SUMS.txt` 与 `BUILD_INFO.json`。使用 Apple Development 开发签名，尚未公证，Gatekeeper 仍可能阻止打开；DMG 格式不会改变这一限制。文档网站独立构建和部署，不随 App 安装包交付。
