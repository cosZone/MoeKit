# 操作计划、审核与执行

状态：planned。本文是产品与实施蓝图，尚无可运行应用或已验证的执行能力。

## 计划与执行状态机

所有可修改操作采用统一流程：

1. **生成计划：** 固定对象身份、准确路径、工具版本、动作、HEAD/ref/base、文件风险、扫描时间和恢复选择
2. **人工审核：** 明示影响与保留项、是否可能永久丢失、预期重建成本及工具是否会联网/执行 hooks
3. **准备恢复材料：** 仅在支持并选择时创建；校验失败即停止，不能带着失效备份继续
4. **临近执行复查：** 重新检查身份、ref、文件、忽略内容、锁和活动；重要变化使对应计划项失效
5. **逐项执行：** 同一 common repository 串行；有界并发、超时、取消和逐项结果，不追求一次大命令完成所有事
6. **核验结果：** 重读目录、Git 登记、ref 和实际恢复材料；记录成功、失败、跳过、取消和无法确认

这不是跨文件系统、Git 和外部进程的原子事务。进程中断或部分成功需要如实呈现；停止后不宣称自动回滚。应用自己的锁也不能阻止 IDE、终端或 agent 同时写入，复查只能降低而非消除竞态风险。
