## 复查并停止精确选择的进程

Processes & Ports 新增真实进程停止。主动扫描后，可选择 1–16 个符合条件的当前用户进程，复查每个身份、可执行文件、工作目录、端口及关联警告，确认未保存工作和依赖任务的影响后发送 `SIGTERM`。不会默认选择目标，也不会按名称、项目、进程组或父子关系扩展选择。

- 每次确认使用 60 秒内有效的一次性授权，执行前重新读取整组选中身份，并在逐项发送前复查。目标、执行版本、权限或必要元数据变化／无法读取时拒绝；刷新、筛选、选择、取消或 Demo 模式改变会使旧确认失效
- 使用内核 audit token 绑定 PID 与执行版本，拒绝已退出、PID 复用或重新执行后的旧身份；没有只凭 PID 发信号的回退，不提权、不运行 shell 命令
- 发送成功仅表示信号已提交。界面分别报告已观察到退出、仍在运行或未知；仅在温和停止后仍观察到同一身份时，才允许重新复查并另行确认 `SIGKILL`。没有自动升级、自动重试或后台停止
- 浏览器、应用、IDE、数据库、虚拟机、共享服务、系统、MoeKit 自身及祖先进程仍受保护。未标记保护不证明可安全停止；停止目标的自身处理逻辑也可能影响子进程和外部任务
- 不读取参数、环境变量或浏览器资料，不保存或上传进程历史。工作目录、端口、名称或运行时长不能证明 AI 专用无头浏览器的归属；这类会话识别与清理仍未实现

## 原生多缓存清理与恢复

Tools → Mole → Cleanup 新增主动检查、选择、复查和确认的原生缓存工作流。默认支持当前用户 `~/Library/Caches` 的直属缓存目录；其他所选位置的直属候选目录必须含有效标准签名的 `CACHEDIR.TAG`，且不在 Git 树内。位置和标记仅提供候选依据，不能证明内容可丢弃。

- 必须复查精确路径和完整内容清单，确认已停止相关应用／构建／同步，并确认所有选中内容可以重新生成，才能移入 macOS 原生废纸篓。只操作固定选中批次，不运行广域 Mole `clean`／`purge`
- 每批最多 16 个缓存、共 25,000 个清单项目；检查受时间与数量预算限制。超限、未知或不完整证据保持不可操作。目录祖先不能含符号链接，清单内的链接只按链接处理，不跟随目标
- 仅开放当前用户的内置本地 APFS 范围。项目／worktree／Git 元数据、系统与安全缓存、凭据及 MoeKit 控制目录、云占位和未知权限／ACL／卷状态保持保护；普通项目的 `build`、`dist`、`target` 或 `node_modules` 不会因为名字而获得删除权限
- 准备计划只读；120 秒内的一次性确认固定整批目标和清单。目录、选择、项目保护或模式改变会使计划失效。确认后重新核对整批，再逐项捕获并验证身份后移入原生废纸篓，错误或取消会停止后续项目
- 私有记录只关联本次实际操作。恢复需主动读取记录、重新复查并另行确认，只回到原路径；目标已存在时拒绝，不覆盖、不合并，也不自动恢复

移入废纸篓不释放缓存占用的存储。缓存重新生成可能需要重新下载或使首次运行变慢；使用前应了解选中应用的行为。这套检查面向已停止相关工作负载的普通本地使用，不是 OS 沙箱，也不能阻止持有旧文件描述符的进程继续写入或保证抵御恶意同用户进程竞争。

## 永久删除必须另行确认

只有本应用已完成且内容未改变的缓存废纸篓记录，才能进入独立的永久删除复查。再次展示精确目标与完整清单，确认不可恢复后，才执行这一项记录的删除；不扫描任意废纸篓内容，不清空整个废纸篓，也不改变既有 Downloads `.dmg` 恢复入口的边界。

删除前再次捕获并验证整棵树，再依据不可变清单逐项移入私有槽并核对身份后移除。新出现的路径不会加入删除范围；描述符预算不足时在确认前拒绝。部分删除或未知结果保留可见记录，不自动重试，也不把文件消失当作成功。该操作不能通过 MoeKit 或废纸篓撤销。

报告字节数表示逻辑内容大小，不等于已释放物理空间；打开的文件、硬链接、APFS 快照／克隆可能继续保留物理块，永久删除也不保证立即等量回收空间。

## 验证范围与预览交付

回归覆盖一次性授权、过期、取消、重复确认、真实／Demo 边界、身份与执行版本变化、受保护目标、清单变化、恢复冲突及部分／未知结果。原生信号测试仅启动并操作测试自有辅助进程，核对实际 `SIGTERM`／`SIGKILL`、旧执行版本拒绝与未选同名邻居存活；原生缓存 Trash／恢复／永久删除测试只操作唯一标记和身份约束的合成 fixture，不清理真实用户缓存。

构建、完整 Debug／优化 Release 测试、定向 AddressSanitizer、原生 fixture 与中英文渲染的结果，必须按最终源码对应 CI 记录核实。合成视图和自动化检查不等于完整原生窗口、键盘、VoiceOver、双架构实机或真实用户目录权限已通过手动验收。
